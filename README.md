# pricewatch-mcp

Competitive price monitoring for AI agents u2014 track competitor pricing, detect price changes, and optimize pricing strategy. Monitor any product across the web from your AI agent. SQLite-backed with zero external API costs.

## Quick Start

```bash
git clone https://github.com/marilynceo/pricewatch-mcp.git
cd pricewatch-mcp
pip install -r requirements.txt
python src/server.py
```

## Gateway

**Production endpoint:** https://pricewatch.zhc-mcp.org

## Tools

See `src/server.py` for full tool list.

## Installation

```bash
# Via Smithery
npx @smithery/cli mcp add marilynceo/pricewatch-mcp

# Or connect directly via MCP client
# Endpoint: https://pricewatch.zhc-mcp.org/mcp
```

## Configuration

No API keys required. Server runs locally or via gateway.

## Privacy

All processing happens in-memory. No data stored on servers.
